# Azerbaijani e-mail templates

Supabase sends the sign-in e-mails. Its default texts are in English, so paste
these into **Supabase → Authentication → Emails (Templates)**:

| Supabase template | Subject | Body (HTML) |
|---|---|---|
| Magic Link | `KursTap.az — daxil olmaq üçün link` | `magic-link.html` |
| Confirm signup | `KursTap.az — e-poçtunuzu təsdiqləyin` | `confirmation.html` |
